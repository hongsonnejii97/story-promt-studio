Cài Đặt Prompt Mẫu Toàn Cục

Prompt mẫu này sẽ được lưu cố định và tự động áp dụng chung cho mọi yêu cầu ghép truyện.

Có thể dùng biến {code} hoặc {story}

Mặc định: {code} + \n (Sẽ ghép: Mã truyện + [Xuống dòng] + Prompt)

Mặc định: \n{story} (Sẽ xuống dòng sau Story: và chèn mô tả)

Đã lưu cấu hình thành công!

Hướng Dẫn Sử Dụng StoryPrompt Studio

Cách vận hành công cụ và cấu trúc prompt đầu ra

1

Nhập danh sách truyện

Điền vào khung theo cú pháp:
Mã truyện | Link truyện
Mỗi truyện trên 1 dòng. Có thể dán hàng chục truyện cùng lúc hoặc tải file .txt lên.

2

Tự động lấy mô tả

Hệ thống tự động kết nối đến link truyện, trích xuất tóm tắt/nội dung giới thiệu và làm sạch các quảng cáo, lời chào dư thừa. Bạn có thể sửa trực tiếp mô tả trên bảng kết quả.

3

Sao chép Prompt

Bấm nút Copy Prompt để sao chép từng prompt hoặc nút Copy TẤT CẢ Prompt để dán trực tiếp vào ChatGPT hoặc công cụ AI tạo ảnh.

Cấu trúc Prompt đầu ra: 

Mã truyện + You are an expert at converting written stories into a single photorealistic image.
... [Nội dung quy tắc phân tích và tạo ảnh nghệ thuật chân thực] ...
Technical:
- Aspect ratio 4:5
- Clean white and blue color palette, strictly eliminate yellow/sepia tones.
- Natural skin texture, beautify
Output format:
Return ONLY the final image. Do not explain anything.
Bright, luminous skin tones and backgrounds; the subject always looks beautiful.
An absolutely bright white color palette, minimizing black tones in the image.
Story:
[Nội dung mô tả truyện tự động lấy từ link]
